# Asisted · Informes Asistenciales

**Aplicación de informes de acompañamiento pediátrico**

Desarrollada para uso interno del equipo de cuidado de **Asisted · Desde 1980**.

---

## ¿Qué es?

App web progresiva (PWA) instalable en Android que permite a las cuidadoras generar informes diarios de acompañamiento pediátrico de forma rápida, sencilla y sin lenguaje técnico.

## Funcionalidades

- Datos generales del turno (referencia de paciente, cuidadora, fecha, tipo de atención)
- Estado de ánimo
- Alimentación (tomas, tipo y cantidad)
- Eliminación (micción y deposición)
- Sueño (horario y calidad)
- Medicación administrada
- Incidencias y novedades
- Pendientes para el siguiente turno
- Generación de informe en PDF
- Compartir por WhatsApp o email
- Funciona sin conexión a internet

## Instalación

Abre el enlace en Chrome desde cualquier Android y toca "Añadir a pantalla de inicio":

👉 https://jabuxi.github.io/ASISTED-HSJD

## Tecnología

- HTML / CSS / JavaScript
- PWA (Progressive Web App)
- jsPDF para generación de documentos
